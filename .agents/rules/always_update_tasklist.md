# Permanent Project Rule: Always Maintain & Update User Task List

1. **User Task List Maintenance**:
   - The user-facing artifact `task_list.md` in `<appDataDir>/brain/<conversation-id>/task_list.md` must ALWAYS be kept up-to-date.
   - At every turn where features, copy, or fixes are implemented, the agent MUST update `task_list.md` with:
     - Specific, step-by-step verification tasks in Section 1 ("🟡 בדיקות אימות ממוקדות עבורך (מה לבדוק כעת)").
     - Clear completed items in Section 2 ("🟢 משימות שהושלמו").
     - Backlog / optimization ideas in Section 3 ("🔵 משימות המשך").
2. **Singular Personal Tone**:
   - All client-facing copy must remain 100% in singular first-person ("אני", "איתי", "היומן שלי").
3. **No "אבחון"**:
   - The word "אבחון" must NEVER be used; use "שיחה עם גיא הדס", "שיחה אישית", "תיאום שיחה".
